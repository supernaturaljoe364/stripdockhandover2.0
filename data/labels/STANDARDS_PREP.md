# Nitrate standards: preparation record

All concentrations are **mg/L NO₃⁻** (nitrate ion), the unit on the strip bottle and the unit the software uses.

## Salt

Stanes Hugo 13-0-45 (fertiliser-grade KNO₃), label: 13% N (all nitrate-N), ≥94% KNO₃.

Nitrate fraction of the salt:
- From the label N: 13% × (62.004 / 14.007) = **57.55% NO₃⁻**
- From the purity: 94% × (62.004 / 101.103) = 57.65% NO₃⁻ (agrees within 0.2%)

The label N figure is used. The label gives a minimum, so true values may be a few % higher. This is a systematic error shared by all standards and is stated in the report.
