# Firmware (frozen, reference copy)

`StripDockPanel/StripDockPanel.ino` is a byte-identical copy of the sketch that runs on the Arduino Nano panel
(copied 2026-11-20 from the original on the build PC's Desktop). It passed its hardware safety tests and its
behaviour is **frozen**: do not modify or re-upload it. If you think a change is needed, write the proposal in
PROGRESS.md and discuss it with the team first.

Library: "U8g2" by olikraus. Board: Arduino Nano (ATmega328P). Wiring is in the sketch's header comment.
